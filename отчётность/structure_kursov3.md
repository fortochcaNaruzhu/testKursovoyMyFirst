# Структура репозитория Kursov3

Краткое дерево **основных** каталогов верхнего уровня и ядра симулятора. Служебные каталоги (`.git`, `__pycache__`, `.ipynb_checkpoints`) в дереве не показаны.

## Дерево каталогов (верхний уровень)

```
Kursov3/
├── aboutProject/              # справочные материалы по проекту
├── Anatoliy/
│   └── swarm_mavic/           # связанный проект/наработки (роевые сценарии, миры, логи)
├── books/                     # PDF-литература (локальные копии)
├── BooksDocuments/            # дополнительные PDF-документы
├── drone_env/                 # виртуальное окружение Python (создаётся setup_env.py, обычно не коммитится целиком)
├── Drone_Swarm_Simulator_v2/  # основной симулятор роя (SITL, MAVLink, сценарии, replay)
├── testCoridor/               # материалы по коридорному сценарию (ноутбук, CSV, архив)
├── описание алгоритмов/       # TeX/Markdown: формальное описание алгоритмов
└── отчётность/                # отчёты и заметки по экспериментам и визуализации
```

## Дерево `Drone_Swarm_Simulator_v2/` (ядро курсовой разработки)

```
Drone_Swarm_Simulator_v2/
├── launch_simulation.py       # точка входа: одиночный запуск симуляции
├── run_batch.py               # пакетный запуск серии экспериментов
├── setup_env.py               # установка зависимостей и venv `../drone_env`
├── requirements.txt
├── README.md
├── config/                    # параметры ArduPilot (например iris.parm)
├── core/                      # низкоуровневая логика симуляции
│   ├── control/               # PID и контроллер дрона
│   ├── logging/               # запись телеметрии в CSV
│   ├── mavlink/               # обмен с SITL по MAVLink
│   └── monitors/              # мониторы состояния (скорость, координаты и т.п.)
├── scenarios/                 # сценарии поведения роя (antenna, linear_chain, solo, …)
├── replay/                    # воспроизведение логов (GUI, ROS/RViz2, контроллер воспроизведения)
├── visualizer/                # 2D (matplotlib), публикация позиций, модели для RViz (.dae)
├── scripts/                   # вспомогательные скрипты (replay, графики, Docker-обёртки)
├── tests/                     # unit-тесты (replay, visualization)
├── docker/                    # Dockerfile для replay с GUI/RViz
├── experiments/               # выходные каталоги экспериментов (локально, не для коммита)
├── logs/                      # примеры/кэш логов для replay
└── MAVProxy/                  # вендорный/локальный MAVProxy (editable install из setup_env)
```

## Назначение разделов (кратко)

| Каталог | Назначение |
|---------|------------|
| **Drone_Swarm_Simulator_v2** | Главный код: запуск ArduPilot SITL, сценарии роя, логирование CSV, replay и визуализация. |
| **drone_env** | Изолированное Python-окружение с pymavlink, matplotlib и пр.; путь задаётся правилами workspace (`../drone_env`). |
| **описание алгоритмов** | Научно-техническое описание: антенная логика, коридор, сетка, KA008 и обзор симулятора в LaTeX/Markdown. |
| **отчётность** | Пояснения к экспериментам, логированию, RViz2 и подобная отчётная документация. |
| **books / BooksDocuments** | Справочные PDF (алгоритмы, дроны и т.д.), не исполняемый код. |
| **Anatoliy/swarm_mavic** | Отдельный блок наработок (контроллеры, сценарии corridor/grid, метрики). |
| **testCoridor** | Экспериментальные данные и ноутбук по «коридорной» теме. |
| **aboutProject** | Внутренняя справка (например ссылки на Python-файлы). |
| **.cursor** | Настройки Cursor: правила, skills, команды (инфраструктура IDE, не часть симулятора). |

## Связь с запуском

- Симулятор и тесты запускаются из **`Drone_Swarm_Simulator_v2`** с активированным **`../drone_env`** (см. `README.md` и правила workspace).
- Для **ROS2 / RViz2** обычно отдельно source окружения ROS (`/opt/ros/...`), как описано в отчётах в `отчётность/`.
